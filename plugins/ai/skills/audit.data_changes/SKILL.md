# 数据变更追踪

追踪和查询系统中的数据变更记录，用于审计和问题排查。

## 使用场景

- 查询配置修改记录，了解谁在什么时候修改了什么配置
- 审计操作历史，追踪敏感数据的变更
- 问题排查，查找导致问题的配置变更
- 合规审计，满足审计要求的数据变更追踪

## 资源类型

支持查询以下资源类型的变更记录：

### host

主机配置变更记录。

- 主机信息的增删改
- IP 地址、端口、分组等配置变更
- 主机状态变更

### credential

凭据信息变更记录。

- 凭据的创建、更新、删除
- 密码或密钥的修改
- 凭据关联关系的变更

### cloud_account

云账号配置变更记录。

- 云账号的添加、更新、删除
- AccessKey 或密钥的修改
- 云账号关联关系的变更

### menu

菜单配置变更记录。

- 菜单项的增删改
- 菜单权限配置变更
- 菜单结构变更

### role

角色配置变更记录。

- 角色的创建、更新、删除
- 角色权限的变更
- 角色关联关系的变更

### user

用户信息变更记录。

- 用户账户的创建、更新、删除
- 用户权限的变更
- 用户状态变更（启用/禁用）

## 查询参数

### resource_type

指定要查询的资源类型。不提供则查询所有资源类型的变更记录。

### username

筛选指定用户的操作记录。用于查询特定用户的所有变更操作。

### days

查询最近多少天的变更记录，默认为 7 天。

- 支持自定义天数范围
- 建议根据实际需求设置合理的查询范围

### keyword

搜索关键词，用于模糊匹配变更内容。

- 可以搜索资源名称、配置项等
- 支持部分匹配

## 返回数据

查询结果包含以下信息：

- **变更时间**: 数据变更的时间戳
- **操作用户**: 执行变更的用户名
- **操作类型**: 创建（create）、更新（update）、删除（delete）
- **资源类型**: 变更的资源类型
- **资源标识**: 变更的资源 ID 或名称
- **变更详情**: 变更前后的对比信息
- **操作 IP**: 执行操作的客户端 IP 地址

## 使用示例

**查询最近 7 天的主机配置变更：**
- resource_type: host
- days: 7

**查询特定用户的所有操作：**
- username: admin
- days: 30

**搜索包含关键词的变更：**
- keyword: production
- days: 14

**查询云账号的变更记录：**
- resource_type: cloud_account
- days: 30

## 安全与合规

- 所有数据变更都会自动记录，无法删除或修改
- 变更记录包含完整的审计信息，满足合规要求
- 支持按用户、时间、资源类型等多维度查询
- 变更详情包含变更前后的对比，便于问题排查

## 注意事项

- 查询大量数据时可能需要较长时间，建议合理设置 days 参数
- keyword 搜索是模糊匹配，可能返回较多结果
- 变更记录会长期保存，但建议定期归档历史数据
- 敏感信息（如密码）在变更记录中会被脱敏处理
